CodeBs

An AI assistant that answers questions about a software repository, grounded in its actual code.

Live service status: Checking…

What it will do

Upload a repository, ask something like “Which files handle authentication?”, and get an answer built from the real source files, with references to where it came from.

Where the project stands

This is a learning project, built in the open one piece at a time. It is not the assistant yet.

Done
  • Tested FastAPI service with automated checks on every change
  • Docker image published and deployed automatically
  • Repository walker: decides which files count as source code
Next
  • Respecting a repository’s own ignore rules
  • Uploading a repository
  • Splitting code into chunks, embeddings and retrieval
  • Answers grounded in the retrieved code
